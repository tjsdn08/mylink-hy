# MyLink 최종 기능 테스트

**실행 환경**: Chrome 데스크톱 / Chrome 모바일 또는 기기 개발자 도구 / Firebase 테스트 계정 A·B

| 확인 | 테스트 | 기대 결과 |
| --- | --- | --- |
| [ ] | Google 로그인 후 새로고침 | 로그인 상태 유지, 프로필 표시 |
| [ ] | 프로필 Username·이름·소개글 변경 | 저장 토스트, 새 공개 주소 반영 |
| [ ] | 계정 A가 계정 B의 Username 사용 시도 | 중복 경고, 저장 거부 |
| [ ] | Firebase 보안 규칙 게시 후 타인 Username 문서 덮어쓰기 시도 | permission-denied |
| [ ] | 링크 추가 → 수정 → 삭제 | 목록에 반영되고 각각 알림 표시 |
| [ ] | 공개 URL `/{username}` 비로그인 상태 열기 | 프로필·링크 표시, 이메일 비공개 |
| [ ] | 공개 링크 클릭 후 대시보드 접속 | 클릭 수 증가, 통계 차트 반영 |
| [ ] | 내 프로필 드롭다운 메뉴의 모든 항목 | 공개 페이지·통계·편집·로그아웃 정상 연결 |
| [ ] | 드롭다운 바깥 클릭 및 Esc | 메뉴 닫힘 |
| [ ] | 다크 모드 ON → 새로고침 | 다크 모드 유지, 초기 흰 화면 깜빡임 최소화 |
| [ ] | 다크 모드 OFF → 새로고침 | 라이트 모드 유지 |
| [ ] | 시스템 설정 변경(저장 테마가 system인 경우) | 시스템에 맞게 테마 전환 |
| [ ] | 모바일 너비 320px·375px | 수평 스크롤 없이 링크 조작 가능 |
| [ ] | 저장 완료 시 토스트 연속 표시 | 알림 표시, 직접 닫기 동작 |
| [ ] | `/robots.txt`, `/sitemap.xml` | 정상 응답 |
| [ ] | 공개 프로필 URL 공유 | OG 제목·설명·이미지 표시 |
| [ ] | `npx tsc --noEmit` | 오류 없음 |
| [ ] | `npm run lint` | 오류 없음 |
| [ ] | `npm run build` | 빌드 성공 |
| [ ] | Vercel 최신 커밋 상태 | Ready/성공 |

**주의**: 이 문서는 테스트 절차이며 체크박스는 아직 실행 완료를 뜻하지 않습니다. Firestore 규칙 배포와 실제 Firebase 계정 테스트는 별도로 수행해야 합니다.

## 추가 기능 테스트

- [ ] 프로필 디자인: 테마 크림·라벤더·미드나잇 선택 후 저장, 새로고침해도 유지
- [ ] 배경색 선택 및 버튼 모양 둥근형·캡슐형·각진형 반영
- [ ] SNS URL 등록·삭제 후 공개 프로필 아이콘 반영
- [ ] 링크 설명 및 썸네일 URL 편집 후 표시 확인
- [ ] 대표 링크 설정 시 공개 카드 강조 및 썸네일 표시 확인
- [ ] 링크 비공개 시 공개 페이지 목록에서 제외되고, 재공개하면 복귀
- [ ] 링크 드래그 또는 위·아래 버튼으로 변경한 순서가 새로고침 후 유지
- [ ] Firestore 규칙 게시 후 비로그인 공개 프로필 조회 수 1 증가
- [ ] 통계 화면에 방문 수와 방문당 클릭 수가 표시되는지 확인
- [ ] 크림·라벤더·미드나잇 세 테마의 링크 카드 텍스트 대비 확인
- [ ] 모든 화면에서 브랜드 색상 일관성 확인 및 모바일 너비 320px·375px 확인

**보안 범위:** 현재 비공개 링크는 UI에서만 숨겨지고 Firestore 원본 링크가 비밀 처리되는 기능은 아닙니다.

## 편집 UX 및 QR 최종 점검

- [ ] 링크 관리 / 프로필 / 디자인·SNS 탭 전환 시 입력 화면과 오른쪽 미리보기 동작
- [ ] 디자인 편집 화면에서 테마·배경색·버튼 모양을 바꾼 뒤 미리보기 반영, 저장 전 공개 페이지는 그대로 유지
- [ ] 이름·소개글 인라인 수정, 취소 및 Esc 취소, 저장 후 새로고침 데이터 유지
- [ ] 링크 생성·수정 시 `github.com` 입력하면 `https://github.com`으로 보완, 위험한 URL은 저장 거부
- [ ] 프로젝트·SNS 등 링크 그룹을 설정하고 공개 페이지에서 그룹 제목으로 분리 표시
- [ ] 그룹 없는 기존 링크도 정상 표시, 링크 숨김·대표 설정·클릭 집계 유지
- [ ] 공개 페이지 QR 버튼으로 표시 및 주소 복사, 닫기·Esc 동작
- [ ] QR 생성 서비스가 응답하지 않을 때에도 공개 페이지의 나머지 기능이 정상 동작
- [ ] 동작 줄이기 설정(prefers-reduced-motion)에서 링크 등장 효과 비활성화
- [ ] GitHub Actions Verify MyLink 검사 전부 통과 및 Vercel 배포 성공
